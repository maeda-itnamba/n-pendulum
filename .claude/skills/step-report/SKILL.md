# ステップ報告を書く手順

## 1. 材料を集める

1. どのステップの報告かを確認する。分からなければ質問する
2. docs/n-pendulum-guide.md で、そのステップの「完了の条件」を読む
3. 次のコマンドで、そのステップでした作業を確かめる
   - `git log --oneline` （コミットの一覧）
   - `git status` （まだコミットしていない変更がないか）
4. テストがあるステップなら `cd backend && uv run pytest` を実行し、結果を控える
5. リポジトリ、プルリクエスト、公開URLのうち、関係するものを集める

## 2. 完了の条件を点検する

- 完了の条件を1つずつ、満たしているかどうか確かめる
- 満たしていないものがあれば、報告を書く前にユーザーに伝える

## 3. 次の形で書く

```text
【ステップ】（例：3-1 物理エンジン）
【できたこと】
【確かめた方法】
【AIに頼んだこと】
【困ったこと・質問】（なければ「なし」）
【URL】（リポジトリ、プルリクエスト、公開URLなど）
```

## 書き方の注意

- 短く書く。各項目は箇条書きで1〜3行
- 【確かめた方法】には、実行したコマンドや見た画面など、事実を書く。「動いた」だけで終わらせない
- 【AIに頼んだこと】には、AIに任せたことと、自分で確かめたことを分けて書く
- 自分で確かめていないことを「確かめた」と書かない。分からない項目はユーザーに聞く
- 書き終えたらユーザーに見せて、直したいところがないか聞く

# 設計書：n重振り子シミュレーター

## 1. 全体の作り

```text
[画面 frontend]  --条件(JSON)-->  [計算サーバー backend]
 Vite + TS                         FastAPI
 Canvasに描く   <--結果(JSON)--    physics/ で計算
```

1. 画面で n や初期条件を決め、`POST /api/simulate` に送る
2. 計算サーバーが指定の秒数ぶんを計算し、時刻ごとの状態をまとめて返す
3. 画面は受け取った結果を、時刻に合わせて再生する（再生中は通信しない）

## 2. 物理モデル

### 2.1 記号

| 記号 | 意味 | 単位 |
| --- | --- | --- |
| n | 振り子の数（1〜8） | - |
| θi | 節 i の棒が真下となす角度。反時計回りを正 | rad |
| ωi = dθi/dt | 節 i の角速度 | rad/s |
| αi = dωi/dt | 節 i の角加速度 | rad/s² |
| mi | 節 i の先にあるおもりの質量 | kg |
| li | 節 i の棒の長さ（棒の質量は0とする） | m |
| g | 重力加速度 | m/s² |
| μj = mj + mj+1 + … + mn | 節 j より先にある質量の合計 | kg |

i = 1 が支点に近い側、i = n が先端です。

**向きと単位の約束**（計算・API・画面のすべてで同じにする）

| 項目 | 約束 |
| --- | --- |
| 角度の基準 | 支点から真下の向きを θ = 0 とする |
| 角度の正の向き | 反時計回り。θ = +π/2 で棒は右を向く（x > 0） |
| 座標 | 支点が原点。x は右が正、y は上が正 |
| 単位 | SI単位（rad、rad/s、kg、m、s、m/s²）。度は使わない。API もラジアンでやりとりする |
| 角度の範囲 | 計算中は −π〜π に折り返さない（何周回ったかが分かるように、そのまま足していく） |
| 画面への変換 | Canvas は y が下向きなので、`canvasY = 原点Y − y × 拡大率`、`canvasX = 原点X + x × 拡大率` で変換する。画面で度を表示するときだけ、表示の直前に度に変える |

### 2.2 おもりの位置

支点を原点、右を x、上を y とします。

```math
x_i = \sum_{j=1}^{i} l_j \sin\theta_j,\qquad y_i = -\sum_{j=1}^{i} l_j \cos\theta_j
```

### 2.3 エネルギーとラグランジアン

おもり i の速さの2乗は、位置を微分して

```math
\dot x_i^2+\dot y_i^2=\sum_{j=1}^{i}\sum_{k=1}^{i} l_j l_k\,\omega_j\omega_k\cos(\theta_j-\theta_k)
```

となります。全部のおもりについて足すと、項 (j, k) は i ≥ max(j, k) のおもりすべてに現れるので、係数は μmax(j,k) になります。

```math
T=\frac12\sum_{j=1}^{n}\sum_{k=1}^{n}\mu_{\max(j,k)}\,l_j l_k\,\omega_j\omega_k\cos(\theta_j-\theta_k)
```

```math
V=\sum_{i=1}^{n} m_i g y_i=-g\sum_{j=1}^{n}\mu_j\,l_j\cos\theta_j
```

ラグランジアンは L = T − V、力学的エネルギーは E = T + V です（ガイドの式と同じ）。

### 2.4 運動方程式

各 j について、ラグランジュの運動方程式

```math
\frac{d}{dt}\frac{\partial L}{\partial \omega_j}-\frac{\partial L}{\partial \theta_j}=0
```

を計算します。途中の計算は次のとおりです（Mjk = μmax(j,k)、cjk = cos(θj − θk)、sjk = sin(θj − θk) と書く）。

```math
\frac{\partial T}{\partial \omega_j}=\sum_k M_{jk} l_j l_k\,\omega_k c_{jk}
```

```math
\frac{d}{dt}\frac{\partial T}{\partial \omega_j}=\sum_k M_{jk} l_j l_k\left[\alpha_k c_{jk}-\omega_k(\omega_j-\omega_k)s_{jk}\right]
```

```math
\frac{\partial T}{\partial \theta_j}=-\sum_k M_{jk} l_j l_k\,\omega_j\omega_k s_{jk},\qquad
\frac{\partial V}{\partial \theta_j}=g\,\mu_j l_j\sin\theta_j
```

これらを合わせると、ωjωk の項が打ち消し合って次の式になります。

```math
\sum_{k=1}^{n} M_{jk}l_j l_k\cos(\theta_j-\theta_k)\,\alpha_k
=-\sum_{k=1}^{n} M_{jk}l_j l_k\sin(\theta_j-\theta_k)\,\omega_k^2-g\,\mu_j l_j\sin\theta_j
```

### 2.5 行列の形

上の式を A(θ) α = b(θ, ω) とまとめます。

```math
A_{jk}=\mu_{\max(j,k)}\,l_j l_k\cos(\theta_j-\theta_k)
```

```math
b_j=-\sum_{k=1}^{n}\mu_{\max(j,k)}\,l_j l_k\sin(\theta_j-\theta_k)\,\omega_k^2-g\,\mu_j l_j\sin\theta_j
```

- A は対称行列で、運動エネルギーが T = ½ ωᵀAω と書けることから正定値です。そのため、いつでも α が一意に求まります
- α は `numpy.linalg.solve(A, b)` で求めます（逆行列は作らない）

### 2.6 確かめのための特別な場合

**n = 1（単振り子）**：A = m₁l₁²、b = −g m₁ l₁ sin θ₁ なので

```math
\alpha_1=-\frac{g}{l_1}\sin\theta_1
```

小さい角度では周期 T₀ = 2π√(l₁/g) になります。

**n = 2（二重振り子）**：よく知られた次の式と一致するはずです（Δ = θ₁ − θ₂、D = 2m₁ + m₂ − m₂cos 2Δ）。

```math
\alpha_1=\frac{-g(2m_1+m_2)\sin\theta_1-m_2 g\sin(\theta_1-2\theta_2)-2\sin\Delta\,m_2(\omega_2^2 l_2+\omega_1^2 l_1\cos\Delta)}{l_1 D}
```

```math
\alpha_2=\frac{2\sin\Delta\left(\omega_1^2 l_1(m_1+m_2)+g(m_1+m_2)\cos\theta_1+\omega_2^2 l_2 m_2\cos\Delta\right)}{l_2 D}
```

### 2.7 先端の加速度

先端（おもり n）の加速度は、位置を2回微分して求めます。

```math
\ddot x_n=\sum_{j=1}^{n} l_j\left(\alpha_j\cos\theta_j-\omega_j^2\sin\theta_j\right),\qquad
\ddot y_n=\sum_{j=1}^{n} l_j\left(\alpha_j\sin\theta_j+\omega_j^2\cos\theta_j\right)
```

大きさは |a| = √(ẍn² + ÿn²) です。これは空間に対する加速度なので、真下で止まっているときは0、自由落下しているときは g になります。

## 3. 計算方法

### 3.1 状態と微分

状態は y = [θ₁…θn, ω₁…ωn]（長さ 2n の配列）とします。

```math
\frac{dy}{dt}=f(t,y)=[\,\omega_1\ldots\omega_n,\ \alpha_1\ldots\alpha_n\,]
```

### 3.2 RK4（4次のルンゲ・クッタ法）

自分で実装します。1ステップは次のとおりです。

```math
\begin{aligned}
k_1&=f(t,\ y)\\
k_2&=f(t+\tfrac{h}{2},\ y+\tfrac{h}{2}k_1)\\
k_3&=f(t+\tfrac{h}{2},\ y+\tfrac{h}{2}k_2)\\
k_4&=f(t+h,\ y+h\,k_3)\\
y_{\text{next}}&=y+\tfrac{h}{6}(k_1+2k_2+2k_3+k_4)
\end{aligned}
```

### 3.3 時間刻み dt

**標準は dt = 0.001 秒**とし、API で 0.0001〜0.01 の範囲で変えられるようにします。

- RK4 は誤差が dt⁴ に比例するので、dt を半分にすると誤差は約 1/16 になる
- 二重振り子の速い動きでも、1回の振れ（約1秒）を1000ステップ以上で追えるので、形がくずれない
- 予備計算（下の表）で、3-1の条件「n＝2、30秒でエネルギーのずれ0.01%以内」を大きく下回った
- 計算量は 30秒 × 1000ステップ × 4回（RK4）＝ 12万回の連立方程式で、n ≤ 8 なら数秒以内で終わる見込み（3-1 で実測する）

| 条件（m = 1、l = 1、ω = 0 から開始） | エネルギーの相対ずれの最大 |
| --- | --- |
| n=2、θ=0.5、30秒 | 約 7×10⁻¹⁴ |
| n=2、θ=2.0（カオス的）、30秒 | 約 1×10⁻⁸ |
| n=4、θ=1.0、10秒 | 約 4×10⁻¹² |
| n=8、θ=1.0、10秒 | 約 8×10⁻¹² |

※ AI（Claude）が書いた試しのコードで出した値です。ここでは |E(t) − E₀| / |E₀| で測っています。3-1 で、5章の測り方の正式なテストとして測り直します。

### 3.4 画面に返すデータの間引き

計算は dt ごとに行いますが、画面は1秒に60コマあれば十分です。dt = 0.001 で30秒だと3万点になってデータが大きいので、**返す時刻は 1/60 秒ごとに間引きます**。ただし、加速度の最大値は間引く前の全ステップで探します（間引くと、本当のピークを見逃すため）。

**データ量の見積もり（いちばん大きい n = 8、60秒の場合）**

1コマあたりの数値は、t が1個、θ と ω が8個ずつ、エネルギーと加速度が1個ずつで、合計19個です。

| 返し方 | コマ数 | 数値の個数 | JSON の大きさ | gzip 圧縮後 |
| --- | --- | --- | --- | --- |
| dt ごと（間引かない） | 60,001 | 約114万 | 約22 MB | 約10 MB |
| 1/60秒ごと | 3,601 | 約6.8万 | 約1.3 MB | 約0.6 MB |
| 1/60秒ごと、小数4桁に丸める | 3,601 | 約6.8万 | 約0.5 MB | 約0.2 MB |

※ ランダムな数値で JSON を作り、大きさを測った値です（AI が計算）。

- 間引かないと、スマホの回線では読み込みに時間がかかりすぎる
- **1/60秒ごとに間引き、小数4桁（角度なら0.0001 rad）に丸めて返す**ことにする。画面で見分けられる差よりずっと細かいので、見た目は変わらない
- 丸めるのは返すときだけで、計算そのものは丸めない

## 4. 入れ替えられる作り

運動方程式と RK4 を別のファイルに分けます。RK4 は「状態 y と微分 f」だけを知っています。

```text
backend/physics/
├── integrator.py   rk4_step(f, t, y, dt)、integrate(f, y0, dt, steps)
├── system.py       System：derivative(t, y) と energy(y) を持つ型（Protocol）
└── pendulum.py     NPendulum(m, l, g)：System を満たす。mass_matrix、forcing、tip_acceleration も持つ
```

## 5. 正しさの確かめ方（テスト）

| テスト | 内容 | 合格の基準 |
| --- | --- | --- |
| エネルギー保存 | n=2、dt=0.001、30秒 | ずれが 0.01% 以内 |
| 単振り子の周期 | n=1、θ=0.05 rad から。ゼロを横切る時刻から周期を測る | 2π√(l/g) との差が 0.1% 以内 |
| 二重振り子の式 | 2.6 の式をそのまま書いた別の関数と、ランダムな100通りの状態で α を比べる。さらに10秒計算して軌道を比べる | α の差が 10⁻¹⁰ 以内、軌道の差が 10⁻⁶ 以内 |
| 静止状態 | すべて0から10秒 | θ、ω がずっと0 |
| n=1〜8 | それぞれ10秒計算 | エラーなし。ずれを docs に記録する |
| RK4 単体 | dy/dt = y（答えは eᵗ） | dt を半分にすると誤差が約1/16 |
| 先端の加速度 | 静止で0、θ=π/2 で止まった瞬間の n=1 で g | 差が 10⁻⁹ 以内 |

**エネルギーのずれの測り方**：E₀ が0に近いと割り算が不安定になるので、基準には「位置エネルギーの深さ」g Σ μj lj（いちばん下といちばん上の差の半分）を使います。

```math
\text{ずれ}=\max_t\frac{|E(t)-E_0|}{g\sum_j \mu_j l_j}
```

## 6. 入力の上限

| 項目 | 範囲 | 理由 |
| --- | --- | --- |
| n | 1〜8 | 大きいと計算が不安定になりやすい |
| 角度 θi | −π〜π rad | 一周ぶんあれば足りる |
| 角速度 ωi | −20〜20 rad/s | 速すぎると dt が足りなくなる |
| 質量 mi | 0.1〜10 kg | 0 は A が正定値でなくなる |
| 長さ li | 0.1〜2 m | 0 以下は物理的におかしい |
| 重力 g | 0〜30 m/s² | 0（無重力）も遊べるように許す |
| dt | 0.0001〜0.01 s | 小さすぎると計算が長く、大きすぎると不正確 |
| 計算する秒数 | 0より大きく、60秒まで | 公開したときの負荷を抑える |

範囲外の値は 422 エラー（FastAPI の入力チェック）で返します。配列の長さが n と合わないときもエラーにします。

## 7. API

### 7.1 `POST /api/simulate`

**送るもの**

```json
{
  "n": 2,
  "theta0": [2.0, 2.5],
  "omega0": [0.0, 0.0],
  "mass": [1.0, 1.0],
  "length": [1.0, 1.0],
  "g": 9.81,
  "dt": 0.001,
  "duration": 30.0
}
```

**返るもの**

```json
{
  "t": [0.0, 0.0167, 0.0333],
  "theta": [[2.0, 2.5], [1.99, 2.49]],
  "omega": [[0.0, 0.0], [-0.12, 0.08]],
  "energy": [-9.81, -9.81],
  "tip_accel": [12.3, 12.1],
  "max_tip_accel": { "value": 85.2, "t": 4.731, "x": 0.82, "y": -1.31 },
  "energy_drift": 1.1e-8
}
```

| 項目 | 内容 |
| --- | --- |
| t | 時刻（1/60秒ごと） |
| theta、omega | 時刻ごとの角度と角速度（n 個ずつ） |
| energy | 時刻ごとの力学的エネルギー |
| tip_accel | 時刻ごとの先端の加速度の大きさ |
| max_tip_accel | 全ステップの中での最大値と、そのときの時刻・先端の位置 |
| energy_drift | 5章の式で出したエネルギーのずれ |

### 7.2 基本形から変えたところと理由

- **返す時刻を間引いた**：データを小さくするため（3.4）
- **返す数値を小数4桁に丸めた**：データをさらに小さくするため。画面で見分けられる差よりずっと細かく、計算そのものは丸めない（3.4）
- **`max_tip_accel` を足した**：3-5 のマークに使う。間引く前の全ステップで探さないと、本当のピークを見逃すため
- **`energy_drift` を足した**：画面で計算の正しさを示したり、テストで使ったりするため

## 8. 画面

```text
パソコン                               スマホ（縦に並べる）
+---------------------------+--------+  +-----------------+
|                           | n [2 ▼]|  |                 |
|        ● 支点             | θ1 ─●─ |  |     Canvas      |
|         \                 | θ2 ─●─ |  |                 |
|          ●                | ω  …   |  +-----------------+
|           \               | m  …   |  | ▶再生 ■停止 ↺   |
|            ● ✕85.2m/s²    | l  …   |  +-----------------+
|        ～～軌跡～～  t=4.73 | g ─●─  |  | 設定（折りたたみ）|
|                           |        |  +-----------------+
+---------------------------+--------+
|  ▶再生  ■停止  ↺リセット   t = 12.3s|
+------------------------------------+
```

**表示するもの**
- 振り子（棒とおもり）。おもりの大きさは質量に合わせる
- 先端の軌跡。古いところほど薄くなって消える（3-5）
- 先端の加速度が最大だった地点の ✕ マーク。横に大きさと時刻を書く（3-5）
- 今の時刻とエネルギー

**操作できるもの**
- n（1〜8）をプルダウンで選ぶ。変えると各節の入力欄の数も変わる
- 各節の θ、ω、m、l と、g を、スライダーと数値入力の両方で変える。どちらかを動かすともう片方も変わる。範囲は6章と同じ
- 再生・停止・リセット。条件を変えて再生すると、もう一度計算を頼む
